1. Segurança e navegação: Para que serve o atributo target="_blank" e porque é fundamental acrescentar rel="noreferrer noopener" sempre que abrimos um link num novo separador? 
Resposta: O target="_blank" serve para abrir um link num separador novo do navegador, sem fechar a página atual. O rel="noreferrer noopener" é importante para segurança, porque ele nao deixa que a nova página tenha acesso à página original e evita a partilha da informação.

2. Escolha de listas: Qual é a diferença funcional entre uma lista <ul> e uma lista <ol>? Deem um exemplo prático de um tipo de conteúdo para cada uma. Resposta: A <ul> é utilizada quando a ordem dos elementos não é importante, mostrando marcadores (pontinhos). Por exemplo, uma lista de monumentos para visitar na cidade da Praia. Já o <ol> é utilizada quando os elementos precisam de seguir uma ordem específica, apresentando números. Por exemplo, os passos para preparar uma receita.

3. Tabelas e semântica: Porque é proibido em HTML moderno utilizar o elemento <table> para definir a disposição visual (layout) de uma página? Qual é o único objetivo legítimo de uma tabela? 
Resposta: Em HTML moderno, não devemos utilizar o elemento <table> para organizar visualmente uma página porque as tabelas foram criadas para apresentar dados organizados em linhas e colunas, e não para construir layouts. Para organizar o conteúdo de uma página, devemos utilizar CSS, Flexbox ou Grid. O único objetivo de uma tabela é apresentar dados relacionados de forma estruturada, facilitando a sua leitura e compreensão.
